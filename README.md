# R1 Pro ChArUco Mount

3D-printable mount that holds a `200 × 150 × 4mm` [ChArUco board](https://www.calitar.com/Charuco-Target/CALI100020TAR) on the end effector of a **Galaxea R1 Pro** ([2026 version](https://docs.galaxea-dynamics.com/R1Pro/en/docs/2026/)) for eye-to-hand extrinsic calibration.

**No drilling needed.** The board slides into a slot and screws clamp it from behind.
